# Argus Road Alert
Native SwiftUI iOS app (iOS 17+) that warns you by sound, voice and notification when approaching cameras in Greece.
Data: OpenStreetMap (Overpass), optional custom JSON feed, your own "Report here" pins. Waze button opens Waze.

## Build the IPA on GitHub
1. Create a repo, push these files to `main`.
2. Open the Actions tab, run "Build IPA" (it also runs on every push).
3. Download the `ArgusRoadAlert-ipa` artifact.
4. The IPA is UNSIGNED. Install it with Sideloadly or AltStore using your Apple ID (free ID = 7-day signing), or sign it with your own certificate.
